Option 1: Local server (recommended)
  Windows: double-click start-server.bat (needs Python installed)
  Mac/Linux: run ./start-server.sh
  Then open http://localhost:8000 in your browser. Press Ctrl+C to stop.

Option 2: VS Code
  Install the "Live Server" extension, right-click index.html, choose "Open with Live Server".

Option 3: Just double-click index.html (works without a server too).

Keep the css, js and assets folders next to index.html.
To put it online for free: upload this folder to GitHub and turn on GitHub Pages (Settings > Pages).
